# CRUD-Farmacia

![GitHub license](https://img.shields.io/github/license/larialv12/crud-farmacia)
![GitHub stars](https://img.shields.io/github/stars/larialv12/crud-farmacia)
![GitHub issues](https://img.shields.io/github/issues/larialv12/crud-farmacia)


Este é o projeto BackEnd de uma aplicação para uma farmácia, desenvolvido com o objetivo de oferecer uma interface simples e eficiente para gestão e visualização de produtos farmacêuticos.

- [Funcionalidades](#funcionalidades)

## Funcionalidades

- Cadastro de novos produtos
- Edição de produtos existentes
- Exclusão de produtos

## Tecnologias

- Java 17
Spring Boot
Spring Web
Spring Data JPA
Validation
MySQL
Maven

## Instalação

```bash
# Clone o repositório
git clone https://github.com/larialv12/crud-farmacia.git

# Entre no diretório
cd crud-farmacia

# Instaleências
npm install
```

## Como usar

```bash
npm start
```
